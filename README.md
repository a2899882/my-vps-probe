# My VPS Probe · 极简私有探针（低内存三面板共存增强版）

轻量、自托管的 VPS 状态探针。单个 Go 主控 + 单个 Go 被控端，提供实时资源监控、TCP 延迟历史、月流量配额、到期自动延期、**自定义分组名称与位置排序**、**节点级 Telegram 通知开关**、**TCP 三网断流（疑似被墙）智能告警**与**零停机全量热备份/恢复**。

## 核心亮点与本次升级特性

- **SSH `tz` 管理终端彻底修复**：
  - 移除破坏性的 `clear`（`\033[3J`）清屏指令，进出 `tz` 菜单完整保留 FinalShell / Xshell 上方的全部 SSH 历史滚动缓存记录。
  - 增加 `stty sane` 与光标/色彩自动恢复陷阱（`trap`），改用标准回车交互与非递归主循环，彻底解决退出或 `Ctrl+C` 后终端输入隐身、回显错乱的问题。
- **三面板零冲突共存与 456MB 极低配机器优化（探针 `tz` + Nexus-Flux `fl` + NexusGate-Plus `ng`）**：
  - **Caddy 独立块反代共存**：`tz` 绑定域名采用 `# BEGIN MY-VPS-PROBE` 独立标记块并自动迁移旧版 `:8080` 配置，绝不覆盖 `Nexus-Flux`（`# BEGIN NEXUS-FLUX`）与 `NexusGate-Plus`（`# BEGIN NEXUSGATE-PLUS`）的反向代理配置。
  - **安全阻止 IP+8080 直连**：采用应用层域名校验 + 智能防火墙协同，开启“阻止 IP+8080 直接访问”后仅允许通过绑定的 HTTPS 域名访问面板，同时完整放行被控端 `/ws` 上报与本机 `Nexus-Flux (6366)`、`NexusGate-Plus` 端口，绝不误封其他面板。
  - **低内存编译与运行保护**：`go build` 默认启用 `GOGC=50 GOMEMLIMIT=220MiB -p 1` 防 OOM 编译；`probe-server` 运行时默认启用 `GOMEMLIMIT=64MiB` 与 SQLite 4MB 页缓存上限，常驻物理内存稳定在 `~14–19 MB`。
  - **内置三面板共存巡检（`tz` 选项 11）**：一键查看探针、`Nexus-Flux`、`NexusGate-Plus` 及 `Caddy` 的实时状态、端口与内存占用，支持一键为 `NexusGate-Plus` 挂载 Caddy HTTPS 域名反代。
- **Telegram 通知精细化机器开关**：
  - 后台“通知”页新增可视化**「机器通知总开关」**面板，支持按分组筛选、按通知状态筛选、关键词搜索，提供“全部开启”、“全部关闭”、“开启/关闭当前筛选”、“反选”快捷操作。
  - 后台“节点”列表直接展示每台机器的 `🔔 开启` / `🔕 关闭` 通知状态按钮，支持一键点击切换及多选批量开启/关闭通知。
- **新增「TCP 三网断流（疑似被墙）告警」**：
  - 当机器在线（与 SG 主控 WebSocket 保持连接），但所分配的全部三网 TCP Ping 目标同时连接超时，持续达到设定秒数（如 180 秒）后自动触发告警。
  - 支持自由选择参与检测的机器（可按分组或单机勾选）、设置**三网断流触发时长（秒）**、**单次断流最多通知次数（如 3 次，0 为不限次数）**与**多次通知间隔时间（分钟）**，并在三网恢复连通后自动推送恢复通知并重置计数。
  - 前台监控卡片、精简表格与后台节点列表均同步显示醒目的 `三网断流` 状态标签，支持按“三网断流”状态一键筛选。
- **分组名称位置调整与重命名**：
  - 后台“节点管理”与“系统设置”新增**「分组名称与位置顺序管理」**，支持将任意分组置顶、上移、下移、置底、按名称/机器数量排序，并支持直接修改分组名称（自动同步更新该分组下所有机器的分组属性），前后端分组标签严格按设定顺序展示。
- **零停机全量热备份与一键恢复**：
  - 支持在 **Web 管理后台**直接点击“下载全量热备份 (`.tar.gz`)”与“上传并恢复全量备份”，无需停止服务或断开被控端连接。
  - `tz` 菜单选项 `9`（备份）自动将最新备份同步至 `/root/my-vps-probe-latest-backup.tar.gz`（方便在 FinalShell `/root` 目录直接右键下载）；选项 `10`（恢复）自动扫描列出本机备份包并支持输入序号 `[1]` 一键恢复，内置 SHA256 校验与失败自动回滚保护。

## 现有面板无缝热更新指南

1. 将新版源码包 `my-vps-probe-main.zip` 上传至主控服务器 `/root/` 目录（例如通过 FinalShell 下方文件窗口拖入 `/root`）。
2. 在 SSH 终端执行以下一行命令完成首次升级（自动保留全部 62+ 台节点配置、月流量与历史数据库，并安装新版 `tz` 命令）：

```bash
unzip -oq /root/my-vps-probe-main.zip -d /tmp/probe-up && bash /tmp/probe-up/my-vps-probe-main/install-master.sh && rm -rf /tmp/probe-up
```

3. 升级完成后，后续只需将新包放入 `/root/my-vps-probe-main.zip`（或推送到 Git 仓库），在 SSH 输入 `tz` 选择 `1. 更新探针主控端` 即可一键无损热更新！

## `tz` 管理命令速览

在 SSH 任意位置输入 `tz` 即可打开管理面板，也支持命令行快捷参数：

- `tz`：打开交互式管理菜单（完整保留 SSH 历史滚动缓存）
- `tz update [zip路径]`：从本地源码包或 Git 仓库无损热更新主控与 Agent
- `tz status`：查看主控运行状态与健康检查
- `tz domain`：配置 Caddy HTTPS 域名反代（`# BEGIN MY-VPS-PROBE` 独立块，与 `fl` / `ng` 零冲突）
- `tz block-ip` / `tz allow-ip`：阻止 / 允许通过 `IP+8080` 直接访问面板
- `tz backup`：执行零停机全量热备份并同步至 `/root/my-vps-probe-latest-backup.tar.gz`
- `tz restore [备份路径]`：按列表序号或路径恢复主控配置与历史数据
- `tz check`：进入三面板共存状态巡检与 456MB 低内存调优中心
